# Experience Map and Journey Layout

Read this when mapping a customer's journey for a campaign, service or retention plan, or when a strategy needs evidence of where the experience breaks. Parent skill: [`strategy-customer-value-journey`](../SKILL.md).

## 1. Choose the scope level first

| Level | What it covers | Example |
|---|---|---|
| Single interaction | One task on one touchpoint | Booking through a WhatsApp chat |
| Journey | Several channels over time towards one goal | Seeing an ad → site visit → call → visit |
| Relationship | The whole relationship with the organisation | Research → buy → use → renew → refer |

Mismatched scope (the client expects the relationship; the team maps one interaction) is a common cause of scope creep. State the level in the brief.

## 2. Customer experience map (broad)

Columns are phases, for example **Discover → Evaluate → Buy → Use → Advocate** (adapt names). For each phase record: goals, motivations, the trigger to the next phase, questions the customer asks, activities, a satisfaction rating (1–5) and real quotes. Layer a service map beneath it showing what the business does at each phase. Decide whether the map focuses on emotions or on interactions and system actions.

## 3. User journey (specific)

One user group, one scenario, defined goals and expectations. Rows: **Thinking / Feeling / Experience / Digital touchpoints**. Columns: the chronological stages of the scenario (for an insurer: get quote → generate quote → send quote → policy issued → maintenance and support → payment and billing). Mark in each cell the friction, missing capability and emotional state (frustration, anxiety, relief, indifference). The marked cells are the intervention points.

## 4. Conversion funnel matrix (for digital journeys)

Rows: **suspect → lead → prospect → customer → reference (advocate)**. Columns: what the user does; what the business wants; functionality needed; the validated learning (a measurable question) for that stage. "How intrigued were visitors?" is not measurable; "What share of landing-page visitors from paid social submitted the form?" is.

## 5. Evidence

Build maps from interviews, support logs, listening data and analytics; label assumptions. Talk to unexpected stakeholders (front desk, delivery riders, sales assistants). Every cell should cite its source or say "assumption".
