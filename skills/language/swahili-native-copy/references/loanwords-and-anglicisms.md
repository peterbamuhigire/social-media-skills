# Swahili Loanwords and Anglicisms

**Purpose**: Handle borrowed words the native way — use the integrated Arabic loans freely, render technology and business terms in their established Swahili forms, and avoid the bare-English calques that mark translated copy.

**Read this when**: You are writing copy with technology, business, or modern-life vocabulary, or reviewing Swahili that is peppered with untranslated English.

## Arabic loans are native Swahili — use them freely

Much of everyday Swahili is Arabic-derived and fully native. These are not "borrowings to avoid"; they are the normal words.

- `asante` (thanks), `karibu` (welcome/near), `safari` (journey), `lazima` (must), `tayari` (ready), `bei` (price), `biashara` (business), `faida` (profit/benefit), `hakika` (certainty), `salama` (peace/safety), `rafiki` (friend), `wakati` (time), `dakika` (minute), `saa` (hour/clock), `barua` (letter), `habari` (news), `dini` (religion), `bahati` (luck).

## Technology and modern terms — use the established Swahili form

Swahili has standard, widely used terms for modern concepts. Use them; do not leave the English bare.

| English | Native Swahili | Note |
|---|---|---|
| email | `barua pepe` | standard; not a literal coinage |
| website | `tovuti` | standard, widely used |
| internet | `intaneti` / `mtandao` | `mtandao` = network/online |
| online | `mtandaoni` | "on the network" |
| mobile phone | `simu ya mkononi` / `simu ya kiganjani` | "phone of the hand/palm" |
| computer | `kompyuta` | accepted loan |
| app / software | `programu` / `programu-tumizi` | `programu` widely understood |
| download | `pakua` | verb |
| upload | `pakia` | verb |
| account | `akaunti` | accepted loan |
| password | `nenosiri` | standard coinage |
| message | `ujumbe` | |
| customer | `mteja` (pl `wateja`) | |
| order (purchase) | `oda` / `agizo` | `agizo` more formal |
| discount | `punguzo` / `ofa` | |
| service | `huduma` | |
| product / goods | `bidhaa` | |
| price / cost | `bei` / `gharama` | |
| payment | `malipo` | |
| free (no cost) | `bila malipo` / `bure` | |

Accepted loans (`kompyuta`, `akaunti`, `intaneti`, `oda`, `ofa`, `tiketi`, `benki`) are fine and read naturally. The error is leaving raw English (`email`, `online`, `website`, `checkout`) untranslated inside Swahili copy.

## Calques to avoid

| English | Calque to avoid | Native Swahili |
|---|---|---|
| Welcome to our website | `Karibu kwa tovuti yetu` | `Karibu kwenye tovuti yetu` / just `Karibu!` then content |
| Click here | `Bonyeza hapa` (weak as link text) | name the action: `Tazama bei zetu`, `Pata maelezo zaidi` |
| Learn more | `Jifunze zaidi` (literal) | `Pata maelezo zaidi` / `Soma zaidi` / `Fahamu zaidi` |
| Contact us | `Wasiliana sisi` (wrong) | `Wasiliana nasi` |
| Get started | `Pata kuanza` | `Anza sasa` / `Anza hapa` |
| Sign up | `Saini juu` | `Jisajili` / `Jiandikishe` |
| Our team | `Timu yetu` (ok) / English "team" | `Timu yetu` / `Wafanyakazi wetu` |
| 24/7 | bare `24/7` | `saa 24 kwa siku, siku 7 kwa wiki` or `wakati wowote` |
| We offer solutions | `Tunatoa solutions` | `Tunatoa suluhisho` / `Tunakupa ufumbuzi` |

Common structural calque errors:

- Wrong preposition with `wasiliana`: it takes `na` ("with") fused as `nasi/nawe/nao` — `Wasiliana nasi` (contact us), not `Wasiliana sisi`.
- Using the human pronoun `wao`/`wa-` for non-human nouns: products are `zi-` (N-class), not `wa-`. "They are easy to use" about `bidhaa` → `zinaweza kutumika kwa urahisi`, not `wao ni rahisi`.
- English word order: adjective after the noun (`bidhaa bora`, not `bora bidhaa`); possessive after the noun (`duka letu`, not `letu duka`).
- Literal "of": prefer the `-a` of association with correct concord over stacking nouns.

## Orthography (spelling) signals

Standard Swahili spelling differences that translation and casual writers miss:

- `ng'` with the apostrophe is a distinct sound from `ng`: `ng'ombe` (cattle), `ng'aa` (shine) vs `ngoma` (drum). Keep the apostrophe.
- Digraphs: `ny` (`nyumba`), `ch` (`chakula`), `dh` (`dhamana`), `gh` (`ghali`), `th` (`thamani`), `sh` (`shukrani`). Do not anglicise them.
- Double vowels are real and meaningful: `kazi` vs `kaazi` differ; write what the word actually has (`kuu` great, `saa` hour).
- No silent letters; spell phonetically per standard orthography.

## Tanzania vs Kenya

- Tanzania: deeper Swahili, less English code-switching expected; formal copy stays fully in Swahili.
- Kenya: more comfortable English code-switching; some accepted loans appear more readily, but standard copy should still resolve to Swahili terms. Keep `Sheng` out of standard copy.
- When the audience is "East Africa / regional", default to full `Kiswahili sanifu` with accepted loans — it is understood everywhere.

### Term-level differences (choose by market)

| English | Kenya tends to | Tanzania tends to |
|---|---|---|
| toilet / restroom | `choo` | `msalani` |
| school | `skuli` | `shule` |
| ticket | `tikiti` | `tiketi` |
| tip / gratuity | `tipu` | `bahashishi` |
| brochure | `brosha` | `kabrasha` |
| old town | `mji wa kale` | `mji mkongwe` |
| beer | `biya` | `bia` |

Keep standard spellings in copy (`ghali`, `thamani`, `dhamana`, `rangi`); avoid the regional sound-shifts (`l↔r`, `gh→g`, `dh→z`, `th→s`) and the Tanzanian mainland `-ga` verb ending (`kupikaga`) in written sanifu.

Native-form variants also seen and acceptable: `online` → `mkondoni` (alongside `mtandaoni`); `password` → `neno la siri` (alongside `nenosiri`); `mobile phone` → `simu ya mkono` (alongside `simu ya mkononi`). Pick one form and use it consistently across a page.
