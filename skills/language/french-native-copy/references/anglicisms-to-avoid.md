# Anglicisms and Calques to Avoid in French Copy

**Purpose**: Name the literal English-to-French translations that sound foreign, and give the idiomatic French a native writer would use instead.

**Read this when**: You are adapting English copy into French, or reviewing French that "feels" off without an obvious grammar error — the cause is usually a calque.

## What a calque is

A calque is a phrase translated word-for-word that is grammatically possible but not what a French speaker would say. Calques are the dominant failure mode of translated marketing copy because the grammar passes and only a native ear catches them.

## Phrase-level replacements

| English source | Calque to avoid | Native French |
|---|---|---|
| We offer solutions | Nous offrons des solutions | Nous vous proposons… / Nous concevons… |
| For more information, click here | Pour plus d'informations, cliquez ici | Pour en savoir plus / En savoir plus |
| Customer-focused | Centré sur le client | À l'écoute de nos clients |
| Value for money | Valeur pour l'argent | Un bon rapport qualité-prix |
| Easy to use | Facile à utiliser (weak) | Simple à prendre en main / Intuitif |
| Our support team | Notre équipe de support | Notre service client / Notre assistance |
| Get started | Obtenir commencé | Commencer / Démarrer / Se lancer |
| Learn more | Apprendre plus | En savoir plus |
| Book a demo | Réserver une démo (passable) | Demander une démonstration |
| Reach out | Tendre la main | Nous contacter / Prendre contact |
| Save time and money | Sauver du temps et de l'argent | Gagner du temps et économiser |
| Make an impact | Faire un impact | Avoir un impact / Faire la différence |
| We are committed to… | Nous sommes engagés à… | Nous nous engageons à… / Nous avons à cœur de… |
| Feel free to contact us | Sentez-vous libre de nous contacter | N'hésitez pas à nous contacter |
| Affordable | Abordable (ok) / pas cher (cheap) | Accessible / à un tarif raisonnable |
| 24/7 support | Support 24/7 | Une assistance disponible à tout moment / 7 j/7 et 24 h/24 |
| The top option | Le meilleur de sa catégorie | (avoid the bare claim; show proof) |

## False friends

- `actuellement` = "at present", not "actually" (`en fait`). `actuel` = present-day, not "actual" (`réel`).
- `éventuellement` = possibly, not "eventually" (`finalement`, `à terme`).
- `assister à` = to attend, not "to assist" (`aider`).
- `réaliser` = to carry out/achieve, and informally to realise — for "realise (understand)" prefer `se rendre compte`.
- `sensible` = sensitive, not "sensible" (`raisonnable`, `judicieux`).
- `librairie` = bookshop, not "library" (`bibliothèque`).
- `location` = rental, not "location" (`emplacement`, `lieu`).
- `expérience` covers both "experience" and "experiment"; for user experience say `expérience` but for a trial say `essai`/`test`.
- `confortable` describes physical comfort; for "comfortable with a decision" use `à l'aise`.

## Borrowed English words: keep, adapt, or replace

- Widely accepted in French business: `un email`/`un courriel` (Canada strongly prefers `courriel`), `le web`, `un site`, `le marketing`, `un budget`, `le design`, `un planning`. These are fine.
- Replace where a natural French term exists and reads better: `le support` → `l'assistance`/`le service client`; `un meeting` → `une réunion`; `le feedback` → `un retour`/`vos retours`; `un deal` → `une offre`; `le shopping` → `les achats`; `booster` → `stimuler`/`renforcer`; `digital` → `numérique` (France public sector and quality copy prefer `numérique`).
- Canada/Québec: anglicisms are actively avoided. Use `courriel`, `magasinage` (shopping), `clavardage` (chat), `téléchargement`. If the audience is Québécois, raise the bar on this.

## Structural calques

- English noun stacks → French uses `de`: "customer satisfaction survey" → `enquête de satisfaction client`, not three nouns in a row.
- English progressive ("we are building") → French simple present: `Nous construisons` / `Nous développons`. There is no `-ing` progressive; `en train de` is for genuine ongoing action and is rarely needed in copy.
- English possessive `'s` → French `de`: "the client's project" → `le projet du client`.
- Over-capitalisation of common nouns (English Title Case) → French lowercases; see `references/typography-and-formatting.md`.

## Vocabulary-level calques (sector terms)

These are single-term traps where the reach-for word is wrong. Full themed vocabulary with genders is in `references/vocabulary-by-theme.md`.

| English reach-for | Calque to avoid | Native French |
|---|---|---|
| customer service | service de client | **le service après-vente (SAV) / le service client** |
| deposit money | déposer de l'argent | **verser / effectuer un versement** |
| bank transfer | transfert bancaire | **le virement (bancaire)** |
| direct debit | débit direct | **le prélèvement automatique** |
| log in | loguer | **se connecter** |
| upload | uploader | **mettre en ligne / téléverser** (download = télécharger) |
| dry cleaner (shop) | nettoyage à sec | **le pressing** |
| room service | service de chambre | **le service d'étage** |
| check out (hotel) | check-out | **quitter / libérer la chambre** |
| do the shopping | faire le shopping | **faire les courses** |
| HR | humains ressources | **les ressources humaines (RH)** |
| text me | texte-moi | **envoie-moi un SMS / un texto** |
| starter (menu) | (entrée used for main) | **l'entrée** = starter; main = **le plat principal** |
| library | librairie | **la bibliothèque** (librairie = bookstore) |

## The test

Read the French aloud. If a French friend would pause and say "on ne dit pas ça comme ça" (we don't say it like that), it is a calque. Rewrite from the meaning.
