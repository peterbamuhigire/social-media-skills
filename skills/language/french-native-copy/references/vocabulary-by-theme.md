# French Vocabulary by Theme (with gender)

**Purpose**: A copywriter's working vocabulary for French web, marketing, and product copy — the terms a Francophone professional audience actually uses, each with its gender, plus the calque traps where the natural French differs from a literal English-to-French reach.

**Read this when**: You are writing French copy for a sector (business, finance, tech, hospitality, retail, health) and need the precise native term and its gender rather than a translated approximation.

Gender is shown by article (`le`/`la`/`l'` with m/f noted where the article hides it). ✗ marks a calque to avoid.

## Affaires, travail, bureau (priority)

les affaires (f pl) — business · la société / l'entreprise (f) — company · le siège social — head office · la succursale — branch · le directeur général (le DG) — CEO · le cadre — executive · le personnel — staff · le/la client(e) — client · le contrat — contract · la proposition — proposal · le devis — quote/estimate · le rapport — report · le compte rendu — minutes/write-up · la réunion — meeting · la salle de conférence — conference room · l'ordre du jour (m) — agenda · le rendez-vous — appointment · le voyage d'affaires — business trip · le salaire — salary.

**Départements**: la comptabilité — accounts · le service marketing · le service des ventes — sales · **le service après-vente (SAV) / le service client** — customer service (✗ *service de client*) · les ressources humaines (RH) (f pl) — HR (✗ *humains ressources*) · le service juridique — legal.

## Banque, finance, argent

la banque · le compte courant — current account · le compte d'épargne / l'épargne (f) — savings · la carte bancaire — debit card · la carte de crédit · le carnet de chèques — chequebook · le distributeur (DAB) — ATM · le découvert — overdraft · le prêt — loan · l'hypothèque (f) — mortgage · le taux d'intérêt — interest rate · les frais bancaires (m pl) — bank charges · **le virement (bancaire)** — transfer (✗ *transfert*) · **le prélèvement (automatique)** — direct debit (✗ *débit direct*) · le paiement — payment · l'impôt (m) — tax · le bureau de change · le taux de change — exchange rate · les devises (f pl) — foreign currency · l'investissement (m) · les actions (f pl) — shares · la bourse — stock exchange · le comptable — accountant · la commission.

- To deposit money → **verser / effectuer un versement** (✗ *déposer de l'argent*).
- Currency for Francophone Africa: **le Franc CFA (FCFA)** in BCEAO/BEAC zones; l'euro (€) where relevant.

## Technologie, internet, téléphone, médias

l'ordinateur (m) · le portable — laptop / mobile (context) · le logiciel — software · l'application / l'appli (f) — app · le réseau — network · le serveur — server · le site web — website · la page web · **l'e-mail / le mail / le courriel** (m) — email · l'adresse e-mail (f) · la boîte de réception (f) — inbox · la pièce jointe — attachment · le mot de passe — password · le fichier — file · le dossier — folder · le navigateur — browser · le wifi · **en ligne** — online · le SMS / le texto — text message · le smartphone · les médias (m pl) · la chaîne — channel · l'émission (f) — show · les actualités (f pl) — news · la publicité (la pub) — advertisement · le streaming.

- Verbs: naviguer (browse) · **télécharger** (download) · **mettre en ligne / téléverser** (upload) · sauvegarder (save) · **se connecter** (log in, ✗ *loguer*) · envoyer / recevoir.

## Restauration, cuisine (hospitality)

le café · la terrasse · le restaurant · la restauration rapide — fast food · le serveur / la serveuse · le chef · le menu / la carte · la carte des vins — wine list · le menu à prix fixe · l'addition (f) — bill · le pourboire — tip · le service compris / non compris · à emporter / sur place — takeaway / dine-in · la livraison à domicile — home delivery.

- Courses: l'apéritif (m) · **l'entrée (f) = starter** (faux ami — not the main) · **le plat principal** — main course · l'accompagnement (m) — side · le dessert · le petit déjeuner / le déjeuner / le dîner · le repas — meal.
- Aliments: la viande · la volaille — poultry · le poisson · les fruits de mer (m pl) — seafood · les légumes (m pl) · le fromage · les produits laitiers (m pl) — dairy · le pain · le riz · les pâtes (f pl) · les herbes et les épices (f pl).
- Cuisson (agrees with the dish): grillé · rôti · poché · sauté / poêlé — pan-fried · frit · cuit à la vapeur — steamed · mariné · farci — stuffed · fumé — smoked.

## Voyage, transport, hôtellerie, tourisme

l'hôtel (m) · la réception · le/la réceptionniste · la chambre simple / double · la chambre à deux lits — twin · **le service d'étage** — room service (✗ *service de chambre*) · la pension complète / la demi-pension — full / half board · la réservation · une chambre de libre — a vacancy · quitter / libérer la chambre — to check out.

- Transport: la voiture · le bus · le car — coach · la navette — shuttle · le train · la gare · l'avion (m) · l'aéroport (m) · le vol — flight · le billet — ticket · l'horaire (m) — timetable · la location de voitures — car rental · la station-service.
- Aéroport / tourisme: le passeport · le visa · la carte d'embarquement — boarding pass · l'enregistrement (m) — check-in · la douane — customs · les bagages (m pl) · la visite guidée — guided tour · l'office de tourisme (m) — tourist information · le séjour — stay.

## Commerce, magasins, services

le centre commercial — mall · le grand magasin — department store · le supermarché · le rayon — aisle · la caisse — checkout · le panier — basket · les promotions (f pl) — specials · la livraison à domicile.
- Shops: la boulangerie · la pâtisserie · la boucherie · la poissonnerie · l'épicerie (f) — grocery · la pharmacie · la quincaillerie — hardware · **la librairie = bookstore** (faux ami; library = la bibliothèque) · l'agence de voyage (f) · **le pressing** — dry-cleaner (✗ *nettoyage à sec* as a shop) · le salon de coiffure · le marché · l'agence immobilière (f) — real estate.
- **faire les courses** — to do the shopping/errands (✗ *faire le shopping*, which means leisure browsing).

## Santé, beauté, maison, services

la santé · le médecin · l'infirmière (f) · l'ordonnance (f) — prescription · la consultation · l'hôpital (m) · la pharmacie · le médicament · l'assurance (f) — insurance · la beauté · le maquillage · les soins de beauté (m pl) · le soin du visage — facial · la crème hydratante — moisturiser · la maison · l'appartement (m) · le loyer — rent · le locataire / le propriétaire — tenant / landlord · le ménage — cleaning · les services d'urgence (m pl) · l'ambulance (f) · les sapeurs-pompiers (m pl) — firefighters.

## Temps, jours, mois, nombres

l'heure (f) · la minute · midi / minuit · le matin / l'après-midi (f) / le soir · les jours (m): lundi…dimanche · les mois (m): janvier…décembre (lowercase) · la semaine · le week-end · l'an / l'année.
- Nombres: soixante-dix (70), quatre-vingts (80), quatre-vingt-dix (90), cent, mille, un million. **Francophone-African note**: *septante (70)* and *nonante (90)* are recognised in some markets; *quatre-vingts* is universal.
- Format: **decimal comma, thin-space thousands** — `12,50 €`, `55 500` (see `typography-and-formatting.md`).

## Useful high-value phrases

- `Je voudrais…` — polite request opener · `C'est combien ?` — how much · `Avez-vous … de libre ?` — do you have … available · `Entrée gratuite / Prix réduit / Soldes` — free admission / reduced price / sale · `Service compris` · `Livraison à domicile` · `Horaires d'ouverture` — opening hours.
