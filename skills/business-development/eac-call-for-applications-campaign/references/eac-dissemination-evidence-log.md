# EAC Dissemination Evidence Log

## Log Fields

| Field | Purpose |
|---|---|
| Country | EAC Partner State targeted. |
| Partner/channel | Chamber, association, hub, platform group, media, email list, social channel. |
| Contact/source | Verified source for the partner or channel. |
| Language | English, French, Kiswahili, or other. |
| Asset shared | Which approved copy/version was sent. |
| Date/time | With timezone. |
| Owner | Person responsible for the outreach. |
| Evidence | Screenshot, email sent copy, post URL, acknowledgement, analytics export. |
| Follow-up date | Reminder or escalation date. |
| Notes | Access issues, bounce, partner response, correction needed. |

## Eight-State Control

Track Kenya, Uganda, Tanzania, Rwanda, Burundi, South Sudan, DRC, and Somalia separately. If a state has no verified partner channel yet, mark it as a gap and escalate before launch.

## Verification Rule

Do not publish a partner directory from memory. Verify names, links, contacts, and relevance close to launch and record the source/date.
