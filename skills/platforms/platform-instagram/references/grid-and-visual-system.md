# Instagram Grid and Visual System Brief

Merged from skills/platforms/platform-instagram-visual-system on 2026-09-29 at cda737c (S04 tree); preservation map: [platform-instagram-visual-system.md](../../../../docs/kaizen/consolidation-2026-09-29/preservation/platform-instagram-visual-system.md)

## When to use this reference

Read this reference when the client needs a written visual brief for its Instagram feed: grid style, mood-board direction, palette documentation, editing preset and a visual standards document that a designer or content creator can implement without further instruction.

Scope is planning only. This reference produces a written brief and standards document. It does not produce graphic designs, images, presets, colour choices applied to artwork, or any other visual asset; production is done by the client's designer or content creator from the brief. Visual execution, typeface choice, type scale, colour systems and layout craft route to the design engine, design-system-skills (https://github.com/peterbamuhigire/design-system-skills), which also carries the anti-AI-slop font doctrine. For brand voice, tone and an existing brand manual, use [04-brand-voice-intake](../../../pipeline/04-brand-voice-intake/SKILL.md), which also owns the cross-platform brand style guide. The parent [SKILL.md](../SKILL.md) rule applies: intentional art direction, readable type and truthful product detail; do not impose a rigid alternating grid, one filter or a luxury colour formula where the evidence does not support it. When a template reduces subject clarity or accessibility, break the template while keeping the brand tokens.

## Decision rules

| Situation | Action | Failure avoided |
|---|---|---|
| Most EA SMEs, limited content budget, irregular posting | Recommend alternating or free-flowing grid | An unsustainable grid that collapses when posting slips |
| No dedicated photographer producing weekly batches of 3+ images per shoot | Do not recommend row-by-row | Broken rows and visible gaps |
| Choosing a grid | Name one style and the reason; never present all five as equally valid | A brief that leaves the decision to the designer |
| Client has a brand identity | Take 3–5 colours from the brand manual as HEX; never approximate from a logo image | Drifting brand colours |
| Building a palette from scratch | Brief the proportional structure (dominant/secondary/neutral) and route colour selection to the design engine | Unsupported colour formulas presented as fact |
| Brand account wants native Instagram filters | Recommend a saved preset in an editing app instead | Native filters vary by source image and cannot be saved as a preset |
| Any image treatment | Check it does not flatten or grey darker skin tones | Misrepresenting people and alienating EA audiences |
| Mood board not yet approved | Hold content production | Rework after production starts |
| A layout, text or specification rule may be platform-dependent | Verify against the current official source before stating | Stale specifications (for example the legacy 20% text rule) |

## Procedure

### 1. Feed grid

The feed is seen as a three-column grid, and the grid's impression matters as much as single posts, so plan the grid before individual posts.

| Style | How it works | Best for |
|---|---|---|
| Alternating | Posts alternate between two visual styles (for example quote graphic / photo) | Brands with limited photography; consistent, predictable rhythm |
| Row-by-row | Each row of 3 shares a colour, theme or format | High-production brands with planned shoots |
| Column-by-column | Each column follows a pattern (for example column 1 products, 2 lifestyle, 3 quotes) | Brands with distinct content pillars |
| Checkerboard | Light and dark posts alternate | Strong-contrast brands; works with two-tone palettes |
| Free-flowing | No strict pattern; cohesion from palette and editing alone | Creator accounts with high photography volume |

Free grid-preview tools to suggest (verify current availability and pricing): Later (desktop/mobile, drag-and-drop grid preview), Preview App (mobile, popular with solo creators), Canva Instagram grid template (fits existing Canva workflows).

### 2. Mood board direction

A mood board sets visual direction before any content is produced and gives designers, photographers and creators a shared reference. The client must formally approve it before production starts; approval is a required gate.

Contents to brief:

1. Colour palette: 3–5 brand colours with HEX codes.
2. Inspiration images: 9–12 showing the desired feel, from Pinterest, Unsplash or Pexels, not competitor accounts.
3. Typography samples: 2 typefaces (headline and body text in graphics). Typeface choice routes to the design engine; do not pick a banned AI-slop face.
4. Tone examples: 3 existing brand photos showing the desired photography style.
5. Rejected direction: 2–3 examples of styles to avoid, to remove ambiguity when briefing creators.

EA-specific direction notes:

- Natural light: bright, abundant natural light is characteristic of the EA environment; work with it rather than correcting it away, and prefer images shot in natural light.
- Authentic environments: EA markets, offices, street scenes and community settings outperform generic stock imagery with EA audiences; say so in the direction notes.
- Skin-tone representation: palettes should complement darker skin tones; avoid high-contrast, desaturated or cool-toned presets that flatten or grey darker complexions, and name this in the rejected-direction section.
- Avoid: overexposed "Western aesthetic" editing, green-screen or unnatural studio backgrounds, overly formal or stiff poses.

Free mood-board tools: Canva (templates; easiest to share with clients), a Pinterest board (collect and organise with the client), Google Slides (shareable for approval and comments).

### 3. Palette documentation

- Existing identity: extract 3–5 colours from the brand manual as HEX codes.
- From scratch, legacy proportional structure to brief: 1 dominant colour at 60% of feed visual weight (the colour most associated with the brand); 1 secondary at 30% (accents, contrast, call-to-action graphics); 1–2 neutrals at 10% (backgrounds, body text, breathing room).
- Legacy harmony guidance (a starting hypothesis for the design engine, not a rule): warm palettes (oranges, reds, yellows, earthy tones) suit EA consumer markets, natural light and cultural colour preferences, and are recommended for FMCG, food and beverage, retail and lifestyle; cool palettes (blues, greys, whites) suit professional services, healthcare, finance and technology. No more than 5 brand colours; more looks chaotic and undermines a cohesive, professional impression.

Record every colour in every format:

| Colour role | Name | HEX | RGB | Pantone | When used |
|---|---|---|---|---|---|
| Dominant | [Name] | #XXXXXX | R=, G=, B= | [PMS] | Backgrounds, primary graphics |
| Secondary | [Name] | #XXXXXX | R=, G=, B= | [PMS] | Accents, CTA buttons, borders |
| Neutral 1 | [Name] | #XXXXXX | R=, G=, B= | [PMS] | Backgrounds, text containers |
| Neutral 2 | [Name] | #XXXXXX | R=, G=, B= | [PMS] | Body text, dividers |

Pantone equivalents are needed only if the client produces print collateral.

### 4. Editing preset

Consistency comes from applying the same adjustments to every photograph, documented as a replicable preset. Apply in this order; values are starting points to calibrate to the client's palette and shooting conditions during onboarding.

| # | Adjustment | Starting range | Rationale |
|---|---|---|---|
| 1 | Exposure | +0 to +20 | Slight brightening for EA bright light and smartphone cameras |
| 2 | Contrast | −5 to +10 | Lower for a warm, inviting feel; higher for bold or fashion brands |
| 3 | Highlights | −10 to −30 | Recover blown skies and windows common in EA outdoor shots |
| 4 | Shadows | +10 to +30 | Open shadows to show detail on darker skin tones |
| 5 | Saturation | −10 to +15 | Lower for neutral or luxury brands; higher for vibrant consumer brands |
| 6 | Colour temperature | +5 to +15 (warm) | Consistent warmth aligned with the palette |
| 7 | Sharpening | +10 to +20 | Offset smartphone softness; avoid over-sharpening portraits |

Record the agreed values as a named preset (for example "BrandName Lightroom Preset"). Do not use Instagram native filters for brand accounts. Recommend Lightroom Mobile (free tier; custom preset shareable by export) or VSCO (free tier; consistent preset application, popular with smartphone-first creators); verify current tiers. Save the preset in the tool and share access with everyone producing content.

### 5. Visual standards document

Compile steps 1–4 into one written brief, which is the deliverable. Sections, in order:

1. **Feed grid style**: chosen style, why it suits this client, and grid rules (for example "every third post must be a quote graphic").
2. **Colour palette**: full table with HEX, RGB, Pantone and a usage rule per colour.
3. **Typography**: headline and body typeface, each with weight, size range and use, and where to obtain it (for example Google Fonts, Adobe Fonts); selection comes from the design engine.
4. **Photography style**: lighting (natural light, golden hour, indoor artificial light), composition (rule of thirds, negative space, close-up product shots), backgrounds to use (plain white wall, wooden surface, outdoor market) and to avoid (cluttered desks, green screen, competitor signage).
5. **Graphic template rules**: logo placement and minimum clear space; text coverage limit (the legacy brief sets text at no more than 20% of the image area; this derives from a retired advertising rule (verify; no register record), so keep it only as a readability choice and verify any current platform requirement before stating one); fixed elements (borders, watermarks, icon sets).
6. **Editing preset settings**: the 7 calibrated values by name, the tool used and where the saved preset is stored.
7. **What to avoid**: a numbered list of at least 5–8 rejected styles, colours, editing approaches or formats specific to this client. This section matters as much as the positive standards because it prevents scope creep and brief drift with external creators.

## Output format

A structured markdown document with clear headings; tables for palette, editing preset and typography; numbered lists for the mood-board checklist and what-to-avoid. The brief is self-contained and written for the client and its creative team; it does not mention this reference or the consultant's process.

## Release checklist

- [ ] Palette documented in HEX and RGB with a clear usage rule per colour; no approximations or colour names alone.
- [ ] One grid style chosen with a stated reason tied to content capacity.
- [ ] Mood board set up as a deliverable the client formally approves before production.
- [ ] Editing standard calibrated with specific starting values for this client; nothing like "adjust to taste".
- [ ] EA photography notes cover skin-tone representation, natural light and authentic East African environments where relevant.
- [ ] The brief stands alone: a designer can implement it without further instruction.
- [ ] Scope stated: a written brief, not graphic design, image files or visual assets; visual execution routed to the design engine.
- [ ] What-to-avoid list has at least 5 client-specific items, not generic advice.
- [ ] Any platform specification (text coverage, tools, filters) verified or labelled.
