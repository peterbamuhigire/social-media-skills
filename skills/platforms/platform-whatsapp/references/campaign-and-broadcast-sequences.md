# Campaign And Broadcast Sequences

Use this reference when WhatsApp is part of a launch, event push, or timed campaign.

Primary source:

- Jeff Walker, *Launch*

## Core rule

Broadcasts should feel like a sequence of useful nudges, not repetitive blasts.

## Recommended campaign flow

1. teaser
2. useful setup or education
3. proof or testimonial
4. offer or event announcement
5. reminder
6. final close or last-call note

## Message discipline

- keep every message short
- make the reason for the message obvious early
- use one CTA only
- keep urgency real and date-specific when possible

## Best CTA verbs for WhatsApp

- reply
- confirm
- ask
- order
- save your place
