## When to use this reference

Read this reference when a client with one or more physical premises wants more footfall from people nearby, not only a complete Google Business Profile. Typical requests: "get more walk-in customers in Ntinda", "local marketing plan for our branches", "geo-targeted ads around the shop", "use WhatsApp groups in our estate", "location tags and check-ins". The GBP setup, optimisation, photo, post, Q&A, review, metric and local SEO sections of [SKILL.md](../SKILL.md) remain the baseline; this reference adds the location-level asset checklist, neighbourhood-specific GBP tactics, geo-targeted paid media, location-tagged content, WhatsApp hyperlocal tactics and multi-branch operation.

## How local discovery works in East Africa

In Uganda, finding a local business is a multi-channel habit. Someone looking for good cake in Ntinda is as likely to ask a WhatsApp group ("aki where can I find good cake in Ntinda?") as to search Google ("bakery near me Kampala"), browse Facebook location tags, or spot signage from a boda-boda. Optimise across all of these touchpoints. Physical signage and word-of-mouth referral networks stay powerful, but digital channels increasingly decide which premises a customer actually walks into; the two must reinforce each other.

Google Business Profile is the highest-priority digital asset for any client with a physical location. A complete, well-reviewed listing appears in Google Maps, Google Search and local results, reaching people actively searching nearby — the highest-intent audience a local business has: they have already decided they want what the client sells and are choosing where to buy it. No social post, however well made, reaches an audience at that moment of decision.

The three primary EA discovery channels to cover in every plan: Google Search (and Maps), WhatsApp referral, and Facebook location tags.

## Inputs

| Input | What to capture |
|---|---|
| Client business name and industry | Trading name; sector (restaurant, clinic, school, hotel, retail, service provider, etc.) |
| Physical location(s) | Specific address(es) or neighbourhood(s) in Uganda/EA, for example "Ntinda, Kampala" or "Plot 14, Kira Road, Kampala" |
| Target radius | Hyperlocal (within 2 km), city-wide (Kampala), or nationwide with flagship branches |
| Primary customer profile | Approximate age range; how they travel to the premises (on foot, boda-boda, private car, matatu); how they currently discover similar businesses |
| Location-level digital presence | Does a GBP exist? Is the Facebook Page address-complete? Is location-tagged content already posted? |
| Single site or branches | If multiple, each branch name and neighbourhood |
| Seasonal or event-driven traffic | School terms, harvest seasons, public holidays, nearby market days, local events that change footfall |

## Decision rules

| Situation | Action | Failure avoided |
|---|---|---|
| Any Essential asset in the checklist below is missing or incomplete | Fix Essential assets before any paid advertising or content strategy; incomplete GBP listings suppress local search visibility | Paying to drive people to a listing that does not rank or convert |
| Location data or targeting could identify a vulnerable person | Aggregate, minimise or do not use it | Privacy and safeguarding harm |
| Neighbourhood business in Kampala on Meta | Pin-drop on the business address, 3–5 km radius | Paying for reach people will not travel from |
| Target is one residential area or estate | 1–2 km radius plus demographic targeting | Diluted spend outside the catchment |
| More than one branch | One ad set, one GBP listing and one content slot per branch | Quiet branches becoming invisible |
| Hyperlocal business considering TikTok ads | Do not run geo-targeted TikTok campaigns; build local presence through content instead | Spend on geography too coarse for neighbourhood targeting |
| Clear search-demand category (dentist, hotel, event venue, school) with a website | Test Google local search ads | Missing high-intent map and local searches |
| Posting into neighbourhood WhatsApp groups | Ask the admin first; offer real value; once a month per group at most | Backlash and removal from trusted groups |
| Any spend, post, message or listing change | Require explicit client authority first | Unauthorised external impact |

## Procedure

### 1. Complete the location digital asset checklist

Mark every asset Exists / Incomplete / Missing, then set the action.

| Asset | Priority | Status | Action required |
|---|---|---|---|
| Google Business Profile — claimed and verified | Essential | | |
| GBP — correct primary category set | Essential | | |
| GBP — minimum 10 photos uploaded | Essential | | |
| GBP — minimum 10 reviews with owner responses | Essential | | |
| GBP — opening hours accurate and up to date | Essential | | |
| GBP — business description with neighbourhood and city keywords | Essential | | |
| Facebook Page — physical address and map displayed | High | | |
| Facebook Page — check-ins enabled | High | | |
| Facebook — location tag applied to posts | High | | |
| Instagram — location tag applied to posts | Medium | | |
| WhatsApp Business — address and location pin in profile | Medium | | |
| Website — address visible, Google Map embedded | Medium | | |
| Foursquare / Yelp listing (if relevant to the sector) | Low | | |

Treat Essential rows as preconditions. Note: this location checklist sets 10 photos as the Essential floor, above the SKILL.md 10-point score's minimum of 8 and its 9-photo minimum viable set; use the higher figure when footfall is the objective.

### 2. Add neighbourhood tactics on top of the GBP baseline

Run SKILL.md Sections 1–8 first, then add:

- **Geo-targeted keywords.** Put the neighbourhood and city in the business description and in individual service descriptions. "The best bakery in Ntinda, Kampala" does better in local search than "the best bakery in Uganda": searches near an area weight results towards it, and a generic national description loses that advantage. (Keep superlatives out of the actual description field — SKILL.md §7 of the completeness score.)
- **Local posts.** Publish GBP updates on location-specific events: neighbourhood market days, promotions timed to nearby schools or churches, public events within the target radius. Posts show directly in local results and on the Maps listing, cost nothing, and competitors often ignore them.
- **Location Q&A seeding.** Add location-specific questions and answers proactively, alongside the ten universal starters in SKILL.md §5: "Where are you located in Kampala?" (full address plus a landmark); "Is there parking at your Ntinda branch?" (a specific answer); "Do you deliver to Kira Road?" (delivery radius plus WhatsApp contact). Seeded answers keep misinformation out of the public field and cut basic location enquiries. (Q&A availability on GBP is time-sensitive: verify at use — no register record.)
- **Street-level landmark photos.** Besides exterior, interior and product/service photos (SKILL.md §3), add photos of nearby junctions, landmarks or boda-boda stages that help customers navigate where addresses are poorly signposted.

### 3. Plan geo-targeted paid media (POEM: Paid; only with spend authority)

Meta (Facebook and Instagram):

- Set the location to Uganda, narrow to the city (Kampala), then to the neighbourhood with the radius or pin-drop tool in Meta Ads Manager.
- Neighbourhood businesses in Kampala: pin-drop on the business address, 3–5 km radius.
- A specific residential area or estate: 1–2 km radius combined with demographic targeting (age; household income proxied by device type).
- Multi-branch: a separate ad set per branch with branch-specific creative ("Now open in Ntinda!" / "Visit our Kyaliwajjala branch").
- Creative must show the physical premises — exterior shot, recognisable staff or a street-level image — to answer the "is this real?" doubt that stops first visits from people who found the business online.

Tool names and targeting options are time-sensitive: verify at use (see register META-AD-STANDARDS for ad policy; no register record for the targeting tools).

TikTok: the source states that, as of 2026, TikTok offers no Uganda geo-targeting precise enough for neighbourhoods (verify before stating; no register record). Build local presence through content instead: film on location, use location hashtags (#Ntinda, #Kampala, #KampalaBusiness) and put Kampala-specific on-screen text in videos.

Google local search ads (formerly Local Campaigns, per the source; verify the current product name at use — no register record): for businesses with a website and a category with clear search demand (dentists, hotels, event venues, schools). They appear in Google Maps results and local Search results beside the GBP listing. Target "[service] [neighbourhood] Kampala" terms — for example "dentist Kololo Kampala", "event venue Bugolobi", "school Ntinda Kampala" — and link to the GBP listing or a dedicated location landing page.

Budget guidance (source planning figures, not benchmarks; confirm against the client's approved budget and current auction costs):

| Line | Monthly figure |
|---|---|
| Minimum viable local Meta campaign (meaningful reach within 5 km in Kampala) | UGX 300,000 |
| Sustained local awareness on Meta | UGX 600,000–1,000,000 |
| Google local search ads minimum test | UGX 500,000 |

### 4. Run location-tagged content (POEM: Owned; staff time only)

1. **Tag the location on every post made from the premises.** Every Instagram and Facebook post from the business carries its location tag, which adds it to the platform's location content and shows it to people browsing that place — a low-effort discovery route most local businesses ignore.
2. **Prompt Facebook check-ins.** Check-ins appear in the customer's friends' feeds as earned social proof with a location signal. Train front-of-house staff to ask: "Have you checked us in on Facebook? It helps us reach more people." Put a small printed counter sign with a QR code linking to the Page check-in.
3. **Use neighbourhood and city hashtags.** A standard location set on every Instagram and TikTok post: the neighbourhood (#Ntinda), the city (#Kampala) and a brand-location compound (#KampalaBakery, #KampalaClinic). These surface content in location searches outside the algorithm's interest graph.
4. **Film behind-the-scenes local content.** The physical space — early-morning preparation, staff arriving, the neighbourhood at different times of day — builds a sense of place that product-only content does not. People who feel familiar with a space are more likely to make a first visit.
5. **Tie content to nearby events.** For a local market, street festival, school prize-giving or neighbourhood event, post: "We're right next to [event] this weekend — come see us after." This signals local roots and captures event-adjacent footfall.

### 5. Run WhatsApp hyperlocal tactics

WhatsApp is the dominant messaging channel in East Africa and works as an informal local discovery network, but no source measures its share of smartphone users in Uganda, Kenya, Tanzania or Rwanda: state no percentage unless it is a named, dated figure with its base, and check the client's own audience data (register WHATSAPP-USAGE-EA-2026, Kaizen WA-01). Treat it as a distinct channel. Messaging must follow the WhatsApp Business Messaging Policy (register WHATSAPP-BUSINESS-POLICY).

- **Neighbourhood groups.** Many Ugandan estates, residential communities and professional circles run WhatsApp groups (estate, parents', church, market-trader groups) with high trust and high open rates. Never spam them — it causes backlash and removal. Identify the admin and ask permission to share a single relevant offer or announcement; offer something of real value (a group-only discount, useful local information, a community event notice); limit outreach to once a month per group.
- **Referral mechanic.** "Share our WhatsApp number with a friend — when they mention your name on their first visit, you both receive 10% off your next purchase." This uses existing trust networks at near-zero cost and converts warm referrals rather than cold ad impressions.
- **Location pin in broadcasts.** Pin the business location on WhatsApp and include it in broadcasts: "Find us here — [WhatsApp location pin]." The source observes that most Ugandan customers navigate by a live WhatsApp location share rather than a written address or Maps link; a pinned location removes a real barrier for first-time visitors.
- **Complete profile.** Business name, category, address, opening hours and a short description naming the neighbourhood; many customers check the profile before a first visit.

For WhatsApp Business set-up, broadcasts and group marketing in depth, use [playbook-sms-whatsapp-marketing](../../../playbooks/playbook-sms-whatsapp-marketing/SKILL.md).

### 6. Run multiple branches (only for clients with more than one location)

- **GBP:** a separate, fully optimised listing per branch — never one combined listing, which loses ranking for every branch because Google treats each listing as a distinct local entity. Each needs branch-specific photos, description and opening hours.
- **Facebook Locations:** use the Locations feature in Meta Business Suite to run branch Pages under one parent brand Page, giving branch-specific posts and check-in counts, separate audience data per branch, and central brand control with local content freedom (feature name time-sensitive; verify at use — no register record). Page set-up detail: [platform-facebook](../../platform-facebook/SKILL.md).
- **Content rotation:** feature branches in turn on the main brand feed. Ntinda customers respond to Ntinda content; Kyaliwajjala customers to Kyaliwajjala content. Posting only from the flagship or busiest branch makes the brand invisible near the quieter ones.
- **Per-branch reporting:** GBP performance per listing (searches, views, direction requests, calls); reach, engagement and check-ins per branch Facebook Page; WhatsApp enquiries attributed to each location where possible. Monitor location mentions, neighbourhood conversations and reviews with [meta-social-listening](../../../meta-analytics-ops/meta-social-listening/SKILL.md).
