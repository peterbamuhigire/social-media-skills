# Repurposing For Launch And Clusters

Use this reference when repurposing must support a campaign, funnel, or topic cluster rather than just produce more posts.

Primary sources:

- Jeff Walker, *Launch*
- Ann Handley, *Everybody Writes*

## Core rule

Repurpose by journey stage, not only by format.

## Four repurposing roles

- discovery asset
- warming asset
- proof asset
- conversion asset

One source piece can feed all four if adapted properly.

## Cluster rule

Where possible, tie derivatives back to:

- a pillar article
- a campaign page
- a lead magnet
- a booking or enquiry step

## Launch sequence

Repurposed assets should usually follow:

1. tease
2. educate
3. prove
4. reveal
5. remind
6. close

## Anti-patterns

- posting the same message unchanged everywhere
- creating derivatives with no next-step link
- pushing direct-sales CTAs at the discovery stage
