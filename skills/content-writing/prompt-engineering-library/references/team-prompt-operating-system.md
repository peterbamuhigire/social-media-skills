# Team Prompt Operating System

Self-contained synthesis prepared from supplied prompt and AI adoption source material. Use it to turn client prompts into managed team assets.

## Prompt Order Form

Each reusable prompt should include: prompt name, owner, business objective, target audience, required source material, brand context block version, output format, platform/channel, constraints and banned claims, approval rule, and examples of accepted and rejected outputs.

## Prompt Matrix For Marketing

| Task | Prompt structure | Review focus |
|---|---|---|
| Caption | Brand context + campaign context + audience + platform + CTA | Voice, accuracy, CTA, compliance |
| Blog/article | Brief + outline + sources + SEO intent + reader action | Evidence, structure, usefulness |
| Report summary | Data source + period + business question + insight format | No invented numbers |
| Reply/DM | Customer message + policy + tone + escalation rule | Empathy, policy accuracy, risk |
| Ideation | Goal + audience + offer + constraints + examples | Fit, originality, feasibility |
| Repurposing | Original asset + channel + audience + required changes | Channel-native adaptation |

## Library Governance

- Version prompts.
- Store approved examples.
- Assign owners.
- Review monthly for performance and safety.
- Retire prompts that generate repeated edits or off-brand outputs.
- Keep sensitive client data out of examples unless access is controlled.

## Quality Testing

Test every team prompt with normal input, incomplete input, off-brand request, unsupported claim request, and urgent/crisis-like request. The prompt passes only if it produces usable output, asks for missing information when needed, and refuses or escalates unsafe requests.
