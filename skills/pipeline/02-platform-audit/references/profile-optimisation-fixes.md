# Profile Optimisation Fixes

Merged from skills/playbooks/playbook-profile-optimisation on 2026-09-29 at cda737c (S04 tree); preservation map: [playbook-profile-optimisation.md](../../../../docs/kaizen/consolidation-2026-09-29/preservation/playbook-profile-optimisation.md)

## When to use this reference

Read this reference when the audit's profile-completeness gaps need turning into fixes: an element-by-element profile checklist per platform, ready-to-publish bio copy, cover-image briefs and a 48-hour / one-week / one-month action plan. It extends the SKILL.md Profile Completeness Scoring Guide (which scores ten elements) and quick-wins list (which names profile fixes at headline level) into a billable profile audit report and action plan. It also serves a standalone "optimise our profiles" request.

Platform specifications below (character limits, image sizes, account-type features, follower thresholds, menu paths) change often. They are the engine's working values, not register-verified facts: verify each against the platform's current help pages before stating it to a client (no register record).

## Inputs

Collect the following before generating the audit and action plan:

| Input | What to capture | If absent |
|---|---|---|
| Client business name | Trading name, and legal name if different | Stop; request it. |
| Industry | Sector and sub-sector (for example financial services: SACCO) | Ask. |
| Country / city | Default Uganda / Kampala | Use the default and label it. |
| Primary goal | Brand awareness / lead generation / product sales / professional credibility | Ask; the CTA depends on it. |
| Active platforms | Every platform with a presence: Facebook, Instagram, LinkedIn, WhatsApp Business, TikTok, X/Twitter, YouTube, Google Business Profile | Audit only the platforms named. |
| Current bios / About text | The existing copy from each platform | Mark "not reviewed". |
| Brand assets available | Logo file (format and resolution), brand colours (hex codes), professional photography (yes/no) | Mark as a gap; brief a designer. |

| Website URL | Primary domain; note if no website exists | Record "no website". |
| Objective, audience and success measure | Approved client brief or accountable owner | Stop and request the missing decision. |

## Decision rules

| Condition | Action | Failure or risk avoided |
|---|---|---|
| A profile must serve discovery and conversion | Prioritise a clear category, proof and one next action. | Decorative profile copy with no route forward. |
| Product, retail, hospitality or service brand | Use the business logo as profile photo. | Unrecognisable thumbnails. |
| Consultant, coach, speaker or personal brand | Use a founder headshot. | A faceless personal brand. |
| Service business with one main conversion route | Point every clickable link to a WhatsApp direct link (`wa.me/256XXXXXXXXX`). | Leaking visitors to a homepage. |
| Business with several destinations | Use a link aggregator (Linktree, Beacons or equivalent) with no more than 4–5 options: website, WhatsApp, current offer, top product/service, optionally a recent post or video. | Decision fatigue. |
| Preferred handle is taken | Append `.ug`, `.kampala` or `.africa`; avoid `_official`, `_real` or year numbers. | Handles that look fake or dated. |
| Gap blocks credibility or conversion | Put it in Priority 1 (fix within 48 hours). | Arbitrary tiering. |
| Inputs and authority are complete | Produce an execution-ready plan. | Unowned actions and hidden assumptions. |
| Evidence or tooling is incomplete | Produce the narrowest qualified draft and a gap list; mark checks `not assessed`. | Treating an unassessed check as passed. |
| Action publishes, spends, contacts people or changes a live profile | Require explicit approval before acting; the deliverable is copy and briefs. | Unauthorised external impact. |

## Procedure

### 1. Apply the universal principles

Apply these standards on every platform before the platform-specific checks.

**Profile photo**
- Logo for product, retail, hospitality and service brands; founder headshot for consultants, coaches, speakers and personal brands.
- Upload at the highest resolution available, minimum 400×400px for all platforms.
- Keep adequate padding for circular crops: the outer 15% of the image is typically cropped on mobile.
- No text in the profile photo; it becomes illegible at thumbnail size.
- Use the same image on every platform: a visitor who finds the brand on LinkedIn after Instagram should recognise it at once.

**Cover / banner image** — the largest piece of owned space on any profile; it must state the brand promise, not just look attractive.
- Include the brand name and tagline unless the profile photo already makes the brand unambiguous.
- Feature a CTA or value statement ("Order via WhatsApp · +256 700 000000" or "Free consultations available").
- Keep brand colours, typography style and imagery consistent across platforms.
- Refresh it for major campaigns, product launches or seasonal moments; treat it as a free advertising panel.

**Username / handle**
- Use the exact trading name wherever possible: no underscores, numbers or punctuation unless the name is taken (then see the decision rule on suffixes).
- Claim the same handle on every platform even if a platform is not active yet: brand squatting is common and handles cannot always be recovered.
- Where a platform indexes the display name for search (Instagram, TikTok), put a primary keyword in the display name rather than the handle.

**Bio copy — WHO-WHAT-WHO-CTA formula** (adapt length and tone to each platform's limit):
1. **WHO you are** — business name and category ("Uganda's leading organic skincare brand").
2. **WHAT you do** — the specific product or service ("Hand-pressed oils and creams made in Kampala").
3. **WHO you serve** — the target audience ("For women who want results without harsh chemicals").
4. **CTA** — one clear next action ("Order via WhatsApp — link below").

Avoid vague descriptors such as "passionate", "innovative" and "dedicated"; every word must earn its place. Write plainly and apply the register from [`east-african-english`](../../../language/east-african-english/SKILL.md).

**Link placement** — see the decision rules on WhatsApp links and aggregators. Update the link destination when a campaign runs; stale links erode trust.

### 2. Run the platform-by-platform checklist

For each active platform, review every element and mark it **Done / Needs Update / Missing**.

**Instagram**

| Element | Standard | Status |
|---|---|---|
| Username | Trading name, no underscores or numbers | |
| Display name | Includes primary keyword (indexed by Instagram search) | |
| Profile photo | Logo or headshot; minimum 200×200px uploaded | |
| Bio | 150 characters; WHO-WHAT-WHO-CTA; line breaks used; max 2 emojis | |
| Link in bio | WhatsApp direct link or Linktree (max 5 destinations) | |
| Account type | Business or Creator (not Personal) | |
| Category | Accurate category selected (for example "Beauty, cosmetics & personal care") | |
| Highlights | 5–8 Highlights; 1–2 word labels; custom branded covers | |
| Contact button | Email or phone number added | |

- Choose a **Business** account for brands running paid promotions, using Instagram Insights or linking a Facebook Page; choose **Creator** for individual influencers, consultants and public figures who want creator analytics and the Creator Marketplace.
- The **display name**, not the username, is indexed in Instagram search: put the keyword there (username `@kampalaskincare`, display name `Kampala Skincare | Organic Beauty`).
- Structure the bio over three visible lines using line breaks (Return on mobile): line 1 value proposition; line 2 credibility signal or differentiator; line 3 location plus CTA pointing to the link.
- **Highlights** cover the most important content categories: Services, Reviews/Testimonials, FAQs, Behind the Scenes, Current Offer. Name each with a single noun where possible ("Services", not "Our Services & What We Do").

**Facebook Page**

| Element | Standard | Status |
|---|---|---|
| Page name | Exact brand name, no keyword stuffing | |
| Vanity URL | Claimed (facebook.com/brandname) | |
| Profile photo | Same image as Instagram; minimum 180×180px | |
| Cover photo | 820×312px; includes tagline or CTA | |
| Short description | 255 characters; clear value proposition | |
| About section | All fields completed: founded date, address, website, WhatsApp | |
| Business hours | Accurate; reflects actual operating hours | |
| Action button | "Send WhatsApp Message" configured | |
| Category | Correct category selected | |
| Pinned post | Active pinned post with current offer or introduction | |

- Claim the **vanity URL** at once (Page Settings > Page Info > Username) using the trading name; once claimed it cannot be transferred to another account.
- The **action button** defaults to "Follow". Change it to **"Send WhatsApp Message"** for EA clients, the highest-converting action for most service businesses. Alternatives: "Call Now" where voice calls are primary; "Learn More" with a link for content-heavy brands.
- Complete **every About field**: Facebook surfaces them in search and Google indexes them; an incomplete About section signals an inactive or untrustworthy page.
- Update the **pinned post** at least quarterly: a current promotion, a brand introduction video, a strong testimonial or a service menu.

**LinkedIn Company Page**

|---|---|---|
| Company name | Exact legal or trading name | |
| Tagline | Up to 120 characters; keyword-rich | |
| Logo | 300×300px; same image as other platforms | |
| Cover image | 1,128×191px; professional; includes tagline | |
| About section | Up to 2,000 characters; primary keywords in first 156 characters | |
| Specialities | 20 keywords added | |
| Website URL | Active and correct | |
| Industry | Accurate category | |
| Company size | Updated | |
| Custom button | "Visit website", "Contact us" or "Learn more" configured | |

- The **first 156 characters** of the About section appear in the LinkedIn search snippet and Google results; treat them as a meta description and open with the main keyword and value proposition.
- **Specialities** (Edit Page > Overview) act as tags for LinkedIn search. Add up to 20 terms, broad ("digital marketing") and specific ("social media management Uganda").
- For **personal profiles** used for business development, complete the Featured section with links to the company website, a recent case study, a credentials deck or a published article; prospects often read it straight after the About summary.

**WhatsApp Business**

| Element | Standard | Status |
|---|---|---|
| Business name | Registered trading name | |
| Profile photo | Logo; same as other platforms | |
| About | Up to 139 characters; direct and informative | |
| Business hours | Set accurately | |
| Business category | Selected | |
| Business address | Completed (if a physical location exists) | |
| Website URL | Added | |
| Catalogue | Minimum 3 products/services with names, descriptions and prices | |
| WhatsApp link | wa.me/256XXXXXXXXX configured and tested | |
| Auto-replies | Greeting message and away message set | |

- The **About field** is visible to anyone opening the profile. Write a one-line promise of what the business does and how to engage ("Quality catering for events in Kampala. DM to book a tasting."). Do not spend characters on "Welcome to our page."
- **wa.me link format**: `wa.me/[country code without +][number]`, for example `wa.me/256700000000`. Add it to every bio, email signature and printed collateral.
- The **Catalogue** is WhatsApp's shop window. Even service businesses should list 3–5 offerings with clear names, short descriptions and prices (or "Price on enquiry"). Clients who browse it before messaging are warmer and convert faster.

**TikTok**

| Element | Standard | Status |
|---|---|---|
| Username | Trading name; consistent with other platforms | |
| Display name | Brand name; may include 1–2 keywords | |
| Profile photo | Same image as other platforms | |
| Bio | Up to 80 characters; punchy and immediate | |
| Link | Website or Linktree (requires 1,000 followers for personal accounts; available immediately on Business accounts) | |

- 80 characters leaves no room for the full formula. Lead with the strongest hook: a bold claim ("Uganda's #1 vegan chef") or a direct CTA ("Watch. Learn. Order 👇").
- Switch to a **Business account** for analytics, the Business Content Hub and a bio link without the follower threshold.
- **Thumbnail consistency**: the first 6–9 videos on the profile grid act as a portfolio; consistent typography, colour or framing signals a professional presence.

**X / Twitter**

| Element | Standard | Status |

- The **bio** is indexed by search engines: include business name, primary service and location in plain language. Example: "Certified accountants in Kampala helping SMEs manage tax and compliance. DM for a free first consultation."
- The **pinned post** is the first post a visitor reads: a high-performing post, current offer, client testimonial or expertise thread; update it for campaigns.
- Apply for a **Professional account** to show the Category label under the bio; it signals legitimacy and helps discovery, especially for B2B and professional-services clients.

**YouTube channel**

| Element | Standard | Status |
|---|---|---|
| Channel name | Searchable; includes primary keyword where natural | |
| Profile photo | Same image as other platforms | |
| Channel art (banner) | 2,560×1,440px; safe area 1,546×423px; includes social handles | |

| Channel trailer | 60–90 seconds; for non-subscribers; explains what the channel does | |
| Sections organised | Homepage sections set up (for example "Popular uploads", "Latest videos") | |

- The **first 150 characters** of the description appear in YouTube search results: state clearly what the channel covers and who it is for, with keywords.
- Keep all text and key visuals inside the **safe area** (1,546×423px centred in the 2,560×1,440px canvas), the only part guaranteed visible on every device.
- The **channel trailer** is shown only to non-subscribers. In under 90 seconds it answers: who is this channel, what will I learn or gain, why subscribe? End with an explicit subscribe CTA.

### 3. Build the action-prioritised improvement plan

**Priority 1 — fix within 48 hours (critical gaps that damage credibility or block conversion)**
- Profile photo missing or very low resolution: upload immediately.
- Bio missing or placeholder text: write and publish the WHO-WHAT-WHO-CTA version.
- No link in bio, or link broken: configure a WhatsApp direct link or Linktree.
- WhatsApp number not visible on any platform: add it to every About/bio field.
- Facebook action button still "Follow": change to "Send WhatsApp Message".
- Personal Instagram account instead of Business/Creator: switch account type.

**Priority 2 — complete within one week (present but underperforming)**
- Bios that exist but do not follow WHO-WHAT-WHO-CTA: rewrite with the formula.
- Generic stock or blank cover images: design branded covers per platform.
- Usernames inconsistent across platforms: standardise where possible (some name changes require follower thresholds or depend on availability).
- Display names without keywords on Instagram and TikTok: update for search.
- Instagram Highlights missing or inconsistently labelled: create 5–8 with branded covers.
- LinkedIn specialities empty: add 20 keywords.
- WhatsApp Catalogue not set up: add at least 3 products/services.
- YouTube description opening with non-keyword text: revise the first 150 characters.

**Priority 3 — implement within one month (polish that lifts a good profile to an excellent one)**
- Facebook pinned post with the current offer or a brand introduction video.
- YouTube channel trailer for non-subscribers.
- WhatsApp Business greeting and away messages.
- Cover images updated across platforms for a consistent visual style.
- Professional/Business account status where available (X, TikTok).
- A quarterly review of all profile elements: bio, cover image, pinned post, link destination.

Give each action an owner, a timing and an acceptance condition, or return it as an unresolved gap.

## Templates

Produce two client-facing documents (PDF or Google Doc, plain language, no technical jargon):

1. **Profile Audit Report** — the completed platform checklists with every element marked Done / Needs Update / Missing, plus a brief note on each gap.
2. **Action Plan** — the three-tier plan, customised with specific rewrite copy for each bio flagged "Needs Update" and a cover-image brief for each platform whose cover is missing or outdated. Rewritten bios are ready-to-publish drafts the client's team can paste straight in.

Character-limit reference for draft copy: Instagram bio 150; TikTok bio 80; WhatsApp About 139; X/Twitter bio 160; LinkedIn tagline 120; Facebook short description 255; LinkedIn About 2,000; YouTube description 1,000; Google Business Profile description 750.

Scenario for illustration only (not client evidence): a Kampala skincare brand with username `@kampalaskincare`, display name `Kampala Skincare | Organic Beauty`, bio line 1 "Hand-pressed oils and creams made in Kampala", line 3 "Kampala · Order via WhatsApp — link below".

## Checklist

- [ ] Complete platform coverage: every active platform is audited; none skipped or given a one-line review.
- [ ] Specific, actionable findings ("Instagram bio reads 'Welcome to our page' — rewrite required"), not vague ones ("bio could be improved").
- [ ] Ready-to-publish bio copy applies WHO-WHAT-WHO-CTA within each platform's limit, not a description of what should be written.
- [ ] Prioritisation is evidence-based: Priority 1 items truly block conversion or credibility.
- [ ] No draft exceeds its platform's character limit (Instagram 150, TikTok 80, WhatsApp About 139, X/Twitter 160, LinkedIn tagline 120).
- [ ] Consistent brand voice across all rewritten bios, aligned to `east-african-english` and the client's stated style.
- [ ] Uganda/EA defaults applied: WhatsApp is the primary CTA mechanism; Facebook is the primary broad-reach platform; platform penetration guidance reflects EA unless the client says otherwise.
- [ ] No graphic design outputs: copy, checklists and written briefs only; visual asset production is referred to a designer.
- [ ] Volatile platform specs verified against current help pages or labelled unverified; inaccessible accounts marked `not assessed`, never healthy.
- [ ] No client fact, benchmark, budget or approval invented; no pattern copied unchanged from another client or channel.
- [ ] Every action has an owner, timing and acceptance condition; nothing is published, changed or spent from planning authority alone.
