# Results reconciliation and honest results writing

Read before writing any advertising results summary for a client. Parent: [advertising-attribution-and-measurement](../SKILL.md).

## 1. Three-source reconciliation table

| Metric | Platform reported | Analytics (GA4 or equivalent) | CRM / POS / mobile money | Explained gap |
|---|---|---|---|---|
| Leads | | | | Windows, view-through, duplicates, consent loss |
| Sales | | | | Offline closes, returns, cancellations |
| Revenue | | | | Refunds, currency, VAT treatment |

Rule: the client's system of record wins for business results; platforms inform optimisation.

## 2. Results summary structure

1. Purpose and period; objective and line in the sand set before launch.
2. Four-level scorecard: message, communication, media, business.
3. Media delivery vs plan (post-buy summary).
4. Business results with the source of truth and incrementality evidence, or "correlation only".
5. Economics: cost per result vs allowable; ROAS vs break-even ROAS; lifetime-value view.
6. Operations readiness during the period.
7. Decisions: scale, hold, fix or stop, each with the reason and the next test.

## 3. Honest language patterns

- "Platforms counted 214 leads; our CRM recorded 167 unique leads, because 31 were duplicates and 16 were outside the target area."
- "Radio enquiries rose while the flight ran; without a control area this is correlation, not proof."
- "Cost per order was UGX 49,200 against an allowable UGX 55,000; we will extend the two best parishes and drop the third."
- "Reach rose, but qualified enquiries per 1,000 reached fell from [a] to [b]; we treat this as a warning."

Avoid without evidence: "viral", "massive growth", "drove sales", "ROI of X%" without a stated model and source.

## 4. Metric hygiene

- Rates and ratios beat cumulative totals (followers, total downloads).
- Every metric carries a definition, window and denominator.
- Break results down by segment and demographic.
- Separate observed from modelled conversions.
