# Objectives and measurement architecture

Read when writing advertising objectives, KPI tables or the measurement section of an advertising plan. Parent skill: [advertising-strategy-and-budget](../SKILL.md).

## 1. Situation analysis before objectives

Include only what bears on this decision (not a term paper).

| Lens | Questions | Evidence |
|---|---|---|
| Company | Brand plans, distribution readiness, capacity to serve demand | Sales, stock, staffing, site uptime |
| Consumer | Who buys, why, what changed recently | CRM, interviews, intercepts, reviews |
| Competition | Who, what they say, where they advertise, how much | Meta Ad Library, media monitoring, outdoor counts |
| Communication | Channel and technology trends affecting reach | Current source register records, client data |
| Internal: operations, finance, personnel | Can we deliver, fund and staff the plan? | Owner interviews |

Framework adapted from Kelley and Sheehan (c. 2021–22) *Advertising Management in a Digital Environment*, Routledge.

## 2. Objective types and matching metrics

| Objective type | Use when | Primary metric | Guard-rail |
|---|---|---|---|
| Awareness | New brand, new area, low recall | Aided/unaided awareness in target, reach at planned frequency | Brand linkage (not just recall) |
| Consideration | Known but not shortlisted | Consideration share, site visits, enquiries | Enquiry quality |
| Lead generation | Considered or high-ticket purchase | Qualified leads, cost per qualified lead | Lead-to-sale rate |
| Sales / trial | Clear offer, working checkout or WhatsApp flow | Orders, cost per order, first-order margin | Returns, refunds, COD refusals |
| Repeat / loyalty | Base exists, repurchase is the lever | Repeat rate, days between orders | Discount dependency |
| Reputation / issue | Tariff change, crisis, policy | Attitude shift, complaint volume, sentiment | Operational follow-through |

## 3. SMART, location-specific objective checks

- Baseline has a source and date.
- Target is justified by model maths, the client's own trend, or a staged plan — never "made up".
- Geography named to district, town, estate or county.
- Enabling milestones listed (e.g. booking link live, staff trained on WhatsApp replies).
- Lifetime value and repeat-rate targets included where repeat purchase matters.

## 4. Four-level measurement plan template

| Level | Metric | Definition | Source | Baseline (date) | Target | Decision rule |
|---|---|---|---|---|---|---|
| Message | Key-message playback | % of exposed sample who restate the single message | Intercept/poll | | | Rework message if below target before scaling |
| Message | Brand linkage | % who name the brand when shown the ad unbranded | Intercept | | | Strengthen branding device |
| Communication | Unaided awareness | % naming the brand first, target segment | Tracking wave | | | |
| Media | Reach / frequency | % of target reached ≥1 and average exposures | Platform, post-buy | | | Re-weight if under-delivered |
| Media | Cost per thousand in-target | Cost ÷ in-target impressions × 1,000 | Platform, audit | | | |
| Business | Incremental orders | Orders in test area minus control area | CRM/POS | | | Scale, hold or stop |
| Operations | Response time | Median minutes to first WhatsApp reply | Inbox export | | | Fix before adding spend |

Rules:
- Measure to judge success and to find improvements.
- Break results down by demographic; averages hide weak segments.
- Diagnose "liked but not linked": high likeability with low message playback and low brand linkage is a branding and message problem, not a media-weight problem.

## 5. Brand purchase funnel diagnostic

Awareness → understanding → consideration → purchase → repurchase → loyalty → advocacy. Read the ratios between stages:

| Gap | Likely cause | First fix |
|---|---|---|
| High awareness, low consideration | Message not credible or not relevant | Re-test value proposition statements |
| High consideration, low purchase | Price, access, friction or trust at the point of sale | Journey handoff and offer review |
| High purchase, low repeat | Product or service experience | Operations and onboarding, not more media |

## 6. Stakeholder side-effects

Record effects on staff morale, dealers and distributors, investors or members. A campaign that swamps an unprepared branch damages the brand.
