# SaaS content web handoff

Return to [SEO and GEO Optimisation](../SKILL.md).

Use the supplied AEO playbook as an intent-planning hypothesis. See the
[dated evidence disposition](../../../../docs/continuous-improvement/2026-09-19-linkedin-aeo-kaizen.md).
Do not repeat its Tally figures as verified benchmarks, attribute revenue to
page structure, promise model repetition, or require an AI text file for ranking.

1. Join the post's audience question to an existing page before proposing a new
   one. Select a use case, template, feature, integration, industry, comparison
   or product page according to the reader's next task. Consolidate duplicate intent.
2. Write a page brief with question evidence, truthful promise, product facts,
   source IDs and dates, limitation, canonical destination, CTA, owner and review
   trigger. A comparison must use like-for-like, dated evidence for both products.
3. Apply the quote test: the answer remains correct when read alone, including
   its material conditions. Do not remove nuance to make a sentence quotable.
4. Hand the brief to the website engine's
   `skills/seo-search/seo/references/saas-intent-content-web.md`, resolving the
   canonical checkout from the global routing table. Website implementation
   owns crawlability, canonicals, links, schema, rendering and deployment checks.
5. Receive the verified destination, publication state, fulfilment test and
   analytics identifier before releasing the social post. A resource must exist
   and work; a comment request must not become automatic marketing enrolment.
6. Measure mentions/citations, referrals, delivered resources, subscriptions and
   qualified enquiries separately. Keep exact prompt samples and denominators
   when reviewing AI visibility; no platform-wide conclusion follows from a
   small convenience sample.

For an optional `llms.txt`, documentation bundle or MCP connection, require a
named consumer and a demonstrated use. Keep implementation in the website or
engineering engine, without implying that these artefacts cause search placement.
If evidence or technical access is missing, return the content brief and mark
the affected check `NOT_ASSESSED`.
