# Launch Sequence Operations

Use this reference when the funnel must support a timed offer, event, product drop, cohort, or campaign window.

Primary source:

- Jeff Walker, *Launch*

## Core rule

Operate the funnel as a sequence with distinct stages, not a flat broadcast calendar.

## Required stages

1. prelaunch list warming
2. education and expectation-setting
3. proof
4. launch open
5. follow-up
6. close

## Operational checks

- define exact open and close dates
- define which segment receives which send
- ensure closed campaigns stop using open-window copy
- document fallback state after close: waitlist, replay, or evergreen offer
