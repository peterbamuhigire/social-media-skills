# Sequence And Proof Architecture

Use this reference when planning a timed campaign, launch, or event promotion.

Primary sources:

- Jeff Walker, *Launch*
- Joanna Wiebe, *Where Stellar Messages Come From*

## Core rule

A campaign is strongest when it stages attention, education, proof, offer, and close in that order.

## Minimum sequence

1. teaser
2. education
3. proof
4. reveal
5. reminder
6. close

## Proof sources

Use:

- testimonials
- customer stories
- outcomes
- founder credibility
- community response

## Anti-patterns

- launching cold with no warm-up
- using urgency before the audience understands the offer
- running a campaign with no explicit proof stage
