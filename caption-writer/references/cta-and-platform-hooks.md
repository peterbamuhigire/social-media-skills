# CTA And Platform Hooks

Use this reference when caption performance depends on stronger openers, cleaner hooks, or better CTA wording.

Primary sources:

- Joanna Wiebe, *Buttons*
- Joanna Wiebe, *Headlines, Subheads & Value Propositions*

## Core rule

A caption hook must stop the scroll.
A caption CTA must tell the reader what they get or do next.

## Hook types

- direct benefit
- problem recognition
- bold opinion
- proof-led
- curiosity gap
- audience qualifier

Do not repeat the same hook type across all three caption variations.

## CTA ladder by platform

- Instagram/Facebook: comment, save, share, DM, visit link in bio
- LinkedIn: comment, connect, read article, book call
- TikTok: comment, follow, watch part 2, DM
- WhatsApp: reply, ask, confirm, order
- X: reply, quote, click thread link

## Friction reducers

Use short reassurance lines when useful:

- `DM us and we'll send details`
- `Reply YES and we'll explain`
- `No pressure. Just ask`

## Anti-patterns

- generic `Learn more`
- two competing asks in one short caption
- same CTA across every platform
- long setup before the hook
